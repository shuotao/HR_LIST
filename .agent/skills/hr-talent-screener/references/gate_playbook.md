# 閘門決策手冊 (Gate Playbook)

> 本檔由 `gatekeeper` agent（`.claude/agents/gatekeeper.md`）在每次 RECORD 後自動蒸餾維護。
> 資料來源：`gate_interactions.jsonl`（append-only 流水帳）。
> 用途：(1) 人可讀的使用者決策模式摘要；(2) gatekeeper PROXY 代打時的唯一判準來源。
> **收錄門檻**：有 2 筆以上互動支持的模式才能進正式節；單一案例放「待觀察」。

## 一、閘門 A 改判模式（使用者背書/推翻的規律）

> 資料基礎：batch_48_20260702（role=default，gate A 差異清單 12 筆，全數由使用者親自簽核）。
> 注意：差異清單本質上只含腳本與 Agent 不一致的筆，不可據此推論腳本整體準確率。

### A-1. E 規則誤殺救回型 → 正式候選（2 筆）

腳本 E 排除規則誤觸（誤讀類別統計行、誤判職稱字面），但履歷實質為**建廠端全系統/建廠機電歷程**時，救回為正式候選。使用者對 Agent 的救回建議全數背書。

- 判準特徵：script_verdict=排除且 score=0，但實質經歷含「建廠廠務／建廠空調製程系統／全系統（MEP/CR/冰機/CDA/UPW/Bulk Gas）／規劃發包監工驗收」。
- 出處：batch_48 seq 002（古凱明，E17 誤觸類別統計行，光電廠建廠廠務副處長）、seq 006（周憲章，E15 誤判，合晶建廠空調製程系統+達運 8y8m 規劃發包監工驗收）。

### A-2. 高分零建廠維修主軸型 → 排除（4 筆）

腳本高分（63~93）但職涯**主軸為維修/裝修/代操且零建廠**者，一律排除。使用者對 Agent 的排除建議全數背書。

- 判準特徵：零建廠 MEP + 主軸為飯店/大樓/商場/遊樂園之機電維修、裝修、代操。
- 加重訊號：軌跡偏離、希望職稱為「維修員」、短期連跳（半年 3 家）。
- 出處：batch_48 seq 025（陳峰 89 分，25 年飯店/大樓機電維修）、seq 009（宋進堂 83 分，純住宅監造+商場飯店維修，同 Batch#47 邱清華型）、seq 010（張哲耀 93 分，遊樂園裝修+污水代操）、seq 023（蔡明融 63 分，CNC/風機設備維修+半年連跳 3 家）。

### A-3. 部分硬底子但主軸偏離型 → 降級觀察（4 筆）

高分（76~86）且**存在一段可驗證的真實工程硬實力**，但主軸零建廠、近期軌跡下滑或機電內涵薄者，降級觀察而非排除。使用者對 Agent 的降級建議全數背書。

- 判準特徵：有一段真實價值區段（營造工地主任 5.5y／證照+試車底子／欣興擴廠 hookup 6y／營造監造），但（a）其餘職涯為裝修/業務/保養，或（b）近期連跳傳產維運軌跡下滑，或（c）機電年資極短（1y2m 兼繪圖）。
- 出處：batch_48 seq 015（李明鴻）、seq 027（馮政儒）、seq 029（黃振庭）、seq 007（周浚亨）。

### 排除 vs 降級的分界線（蒸餾自 A-2 對照 A-3）

**關鍵不在分數，在「是否存在一段可驗證的建廠相關/工程硬實力區段」**：
- 全程維修/裝修/雜打、無可辨識硬底子 → **排除**（A-2）。
- 有一段真材實料（工地主任、試車證照、擴廠 hookup）但主軸偏離 → **降級觀察**（A-3）。

### 待觀察（單一案例，尚不足以成為模式）

- **備而不用救回型（本批唯一使用者推翻案例）**：batch_48 seq 020（王良吉，65 分）——Agent 建議排除，使用者改判降級觀察。理由：電機系出身+曾有廠務 1-2 年類別紀錄，「中鼎若有工地 EHS 缺口可備而不用」。暗示使用者對「本科出身+有廠務痕跡」者傾向留一手而非直接排除；待第 2 筆同型案例佐證。
- **碩士方法論儲備型**：batch_48 seq 018（楊大仟，76 分）——碩士+月台門系統工程方法論扎實但零建廠 → 碩士儲備。使用者背書 Agent 建議。

## 二、閘門 B 答題傾向

> 資料基礎：batch_48_20260702（role=default，gate B 4 題，全數由使用者親自作答）。本批為首次出現閘門 B 資料，跨批次穩定度待後續佐證。

### 觀察傾向（單批 4/4，強訊號但僅一批）

- **B-傾向-1：從不選 C（誤判不調整）— 4/4。** 使用者對每一筆腳本落差都選擇調整規則，未把任何落差當可容忍雜訊放過。顯示對「腳本 vs Agent 判斷不一致」零容忍、傾向根因修正。
- **B-傾向-2：偏好根治/結構型方案 over 輕量關鍵字修補 — 4/4。** 4 題選項 A 皆為較徹底的結構性方案（產業類別解析、統計行結構性跳過、建廠信號豁免詞、E5/E6 擴充＋D6b 加重），選項 B 皆為保守的輕量修補；使用者一律選 A。顯示傾向一次到位的根治，不接受頭痛醫頭的關鍵字補丁。

### 細分方向（各 2 筆，跨批門檻邊緣，暫記待觀察）

- **收緊向（新增排除防線）**：Q1（E12e 產業類別防線：旅館/住宿/休閒/不動產年資佔比 ≥50% 且無建廠信號 → 排除）、Q4（擴充 E5/E6 設備維修關鍵字 CNC/機台組裝/輪轂/風機維護 ＋ D6b 對近 3 段全 <1 年加重扣分）。對應閘門 A 的 **A-2 高分零建廠維修主軸排除**破口的規則落地。
- **放寬向（新增豁免、修誤殺）**：Q2（E 系列比對一律跳過總年資職類統計行）、Q3（發包/驗收/工進納入 E15 建廠信號豁免詞）。對應閘門 A 的 **A-1 E 規則誤殺救回**需求的規則落地。

備註：閘門 B 收緊/放寬雙向並存，本質是「精準化」而非單向鬆緊——A-2 型漏網要補排除、A-1 型誤殺要補豁免，兩者同批發生。下一批 B 資料到位後，若同型細分再各得 1 筆即可升為正式模式。
