### A-1. E 規則誤殺救回型 → 正式候選（3 筆，跨 2 批）

腳本 E 排除規則誤觸（誤讀類別統計行、誤判職稱字面、誤判專案名稱含敏感字眼），但履歷實質為**建廠端全系統/建廠機電歷程**時，救回為正式候選。使用者對 Agent 的救回建議全數背書。

- 判準特徵：script_verdict=排除且 score=0，但實質經歷含「建廠廠務／建廠空調製程系統／全系統（MEP/CR/冰機/CDA/UPW/Bulk Gas）／規劃發包監工驗收／電力與系統規劃」；誤觸原因可能是類別統計行、職稱字面，或**專案名稱字面含敏感機構詞（如「國防部」）但本人並非該機構人員**。
- 出處：batch_48 seq 002（古凱明，E17 誤觸類別統計行，光電廠建廠廠務副處長）、seq 006（周憲章，E15 誤判，合晶建廠空調製程系統+達運 8y8m 規劃發包監工驗收）、default-2026-07-28-review seq 003（吳承融，E19 誤命中專案名「國防部軍備局205廠新建工程」非本人軍職，實質為 4 年電力與系統規劃）。

### A-2. 零建廠維修/維護主軸型 → 排除（5 筆）

職涯**主軸為維修/維護/裝修/代操且零建廠、無可辨識工程硬底子**者，一律排除。使用者對 Agent 的排除建議全數背書。分數非分界關鍵（batch_48 為腳本高分誤放 63~93、batch_50 為腳本全放行後低分 35），核心是「零建廠 + 維修/維護主軸」。

- 判準特徵：零建廠 MEP + 主軸為飯店/大樓/商場/遊樂園/保全樓管之機電維修、維護、巡檢、裝修、代操；desired 常為維修員/作業員/水電工。
- 加重訊號：軌跡偏離、希望職稱為「維修員/作業員」、短期連跳（半年 3 家）、保全樓管業別。
- 出處：batch_48 seq 025（陳峰 89 分，25 年飯店/大樓機電維修）、seq 009（宋進堂 83 分，純住宅監造+商場飯店維修，同 Batch#47 邱清華型）、seq 010（張哲耀 93 分，遊樂園裝修+污水代操）、seq 023（蔡明融 63 分，CNC/風機設備維修+半年連跳 3 家）、batch_50 seq 002（劉傳鑫 35 分，純大樓機電設備維護/巡檢保全樓管業，desired=作業員/水電工）。

### A-3. 有可驗證工程硬底子但主軸偏離/資淺薄型 → 降級觀察（7 筆，跨 3 批）

**存在一段可驗證的真實工程/MEP 監工實力區段**，但主軸零建廠、近期軌跡下滑、機電內涵薄或資淺夾雜者，降級觀察而非排除。使用者對 Agent 的降級建議全數背書（013/018 為 Agent 建議降級獲同意；009 為 Agent 建議排除經使用者上修為降級）。

- 判準特徵：有一段真實價值區段（營造工地主任 5.5y／證照+試車底子／欣興擴廠 hookup 6y／帆宣+機場航廈機電監工／機電監工短期），但（a）其餘職涯為裝修/業務/保養/餐飲，或（b）近期連跳傳產維運軌跡下滑，或（c）機電/MEP 年資極短（1y2m 兼繪圖、監工 5 個月）、資淺（2-3 年），或（d）**履歷資訊量本身不足以判斷 MEP 實質**（無法歸類非因偏離明確，而是內容過於簡略）。
- 出處：batch_48 seq 015（李明鴻）、seq 027（馮政儒）、seq 029（黃振庭）、seq 007（周浚亨）、batch_50 seq 009（李振緯，23.8 年空軍後勤退伍轉職、機電監工僅 5 個月 MEP 過薄、59 歲）、seq 013（謝明景，26 歲/企管/2-3 年、帆宣+機場航廈機電監工潛力但資淺夾餐飲）、default-2026-07-28-review seq 013（洪國清，54 分，詳細履歷沒有更多資訊可判斷 MEP 實質——(d) 型首次獨立出現）。
- **(d) 資訊不足型的意義**：當履歷資訊量不足以確認或否定 MEP 實質時，使用者預設動作是**降級觀察**而非直接排除或直接放行正式候選——「不確定」本身不構成排除理由，也不構成正式候選理由，降級觀察是不確定情境下的安全預設值。此原則對 PROXY 代打有直接參考價值：查無法判斷實質時應傾向降級而非排除／正式，若仍無法比對到具體案例仍應掛起。

- 判準特徵：有電機/工程/廠務底子（本科、繪圖技能、廠務年資）＋ 當前主軸為製造端（設備製造繪圖/組裝、機台操作/製程、in-house 廠務維運觸發 D3/D4）＋ 非建廠。可疊加 junior（總年資 1-2 年）或 senior（20 年製造廠務）兩端。
- 加分保留訊號：能源/擴廠潛力（018）。
- 出處：batch_50 seq 015（陳奎佑 43 分，配電盤製造繪圖/組裝東元+混雜短期）、seq 017（黃名綸 33 分，射出成形機台操作/製程+純消防繪圖 2 段、1-2 年 junior）、seq 018（黃建章 53 分，20 年廠務偏製造業 in-house 維運/生產管理 D3/D4、有能源/擴廠潛力）。

### A-5. 年輕可塑性型（≤27 歲）→ 正式候選，覆寫 Agent 降級建議（3 筆，default-2026-07-28-review 新增正式模式）

**候選人年齡 ≤27 歲時，「總年資少」本身不被視為負面訊號**（使用者認為年輕總年資少屬正常現象），使用者傾向從寬回正式候選，即使 Agent 因分數偏低或年資薄而建議降級觀察。3 筆中 2 筆（004/016）為使用者推翻 Agent 的降級建議、1 筆（003）為 Agent 已先行救回、使用者背書。

- 判準特徵：年齡 ≤27 歲 ＋ 總年資短（因年齡自然合理，非能力不足訊號）＋ 至少一項可辨識的正向底子（EPC/半導體任職紀錄、電力與系統規劃佔比、或單純「可塑性高」的主觀評價）。
- 出處：default-2026-07-28-review seq 003（吳承融，27 歲，4 年間電力與系統規劃佔比重，E19 誤殺救回後年齡因素進一步鞏固回正式）、seq 004（周承泰，25 歲，70 分，亞翔 EPC+京元半導體底，Agent 建議降級被推翻回正式）、seq 016（謝譯葦，25 歲，45 分，可塑性高＋英文中等，Agent 建議降級被推翻回正式）。
- **重要邊界（非無條件）**：年輕不是萬用豁免。batch_50 seq 013（謝明景，26 歲/企管/2-3 年，帆宣+機場航廈機電監工潛力但資淺夾餐飲）年齡同樣年輕，卻維持 Agent 降級建議、未被推翻回正式（歸入 A-3）。差異在於：A-5 者有可辨識的正向工程底子／對口企業經歷；A-3 該案為非工程科系＋經歷夾雜稀釋，即使年輕也不足以覆寫降級。**PROXY 代打時不可僅憑「年齡 ≤27」判正式候選，須同時確認有無正向底子訊號，否則掛起。**

### A-6. 高齡近退休型（58-65 歲）→ 依職涯穩定度分流：穩定=降級／不穩定=排除（3 筆，跨 2 批，新增正式模式）

**候選人年齡逼近或超過一般退休年齡（58 歲以上）時，使用者傾向加重處置**，但處置級別依「近期職涯穩定度」分流：職涯穩定但年事已高、未來發展受限 → 降級觀察；職涯本身已極度不穩定（頻繁換工作）且逼近退休 → 直接排除。

- 判準特徵（降級）：58-60 歲＋近期職涯尚稱穩定，但「退休考量／未來發展受限」為主要疑慮。
- 判準特徵（排除）：60-65 歲＋近年（如 2011 年後）頻繁換工作、職涯極度不穩定——高齡疊加不穩定為排除訊號，非年齡單一因素。
- 出處：batch_50 seq 009（李振緯，59 歲，23.8 年空軍後勤退伍轉職＋機電監工僅 5 個月 MEP 過薄 → 降級）、default-2026-07-28-review seq 014（王建朝，60 歲，35 分，降級+年齡退休考量與未來發展 → 降級）、seq 012（梁澤銘，65 歲，40 分，2011 年後工作極度不穩定頻繁換工作＋逼近 65 歲退休、未來發展堪憂 → 排除，使用者比 Agent 的降級建議更嚴格，直接推翻至排除）。
- **一句話**：高齡本身只到「降級」；高齡 + 職涯不穩定才會被使用者加重到「排除」。

### 排除 vs 降級的三層分界線（蒸餾自 A-2 / A-3 / A-4）＋ 年齡修飾軸（A-5 / A-6）

**關鍵不在分數，在「當前偏離的性質＋是否殘留可用工程底子」**：
1. **完全無工程實質、方向明確偏離**（純大樓/飯店維修維護、純 EHS 職安 ESG、純業務，desired=維修員/作業員/總務人資）→ **排除**（A-2；純 EHS 型見待觀察）。
2. **有電機/工程/廠務底子但當前偏製造端**（製造繪圖/組裝、機台操作、in-house 維運）→ **降級觀察**（A-4）——製造端本身不觸發排除。
3. **有一段可驗證建廠相關/工程 MEP 硬實力區段但主軸偏離、軌跡下滑或資淺薄，或資訊量不足以判斷 MEP 實質** → **降級觀察**（A-3）。
> 一句話：製造端 + 有底子 = 降級（不排除）；純服務/維護/EHS/業務且無工程底子 = 排除；資訊不足 = 降級（安全預設值）。

**年齡是疊加在上述三層之上的獨立修飾軸**（A-5 / A-6），會把原本的判定向上或向下調整一級：
- **年輕（≤27 歲）+ 有正向底子訊號** → 把「總年資少」的扣分中和，甚至覆寫 Agent 的降級建議、拉回正式候選（A-5）。但**若同時存在非工程科系＋經歷夾雜稀釋，年輕不足以覆寫降級**（見 A-5 邊界案例 batch_50 seq013）。
- **高齡（58 歲以上）** → 至少把原判定下修一級（正式候選→降級觀察）；**若疊加職涯極度不穩定（頻繁換工作）** → 再下修一級（降級觀察→排除）（A-6）。
> 換言之：年齡修飾軸的方向盤是「底子/穩定度」，不是年齡數字本身——年輕靠底子加分，高齡靠穩定度減分幅度。

## 二、閘門 B 答題傾向

> 資料基礎：batch_48_20260702（gate B 4 題）＋ batch_50_20260715（gate B 3 題）＋ default-2026-07-28-review（gate B 2 題），皆 role=default、全數由使用者親自作答，共 9 題。

### 觀察傾向（跨 3 批，已達正式門檻）

- **B-傾向-1：從不以「誤判/單次特例」迴避決策 — 9/9（batch_48 4/4＋batch_50 3/3＋default-2026-07-28-review 2/2）。** 使用者從未把腳本落差當可容忍雜訊放過而不表態；即使最終決定「不修規則」（batch_50 Q3、本批 Q2）也是刻意政策並附具體理由（保護寧可多選 ／ 避免對單一質性案例過擬合），而非用「誤判、隨機」帶過。**選項字母不是判準，語意才是（本批新發現）**：本批 Q2 的「C」選項語意其實是「維持人工判斷，推薦不改規則」，並非傳統「C=誤判不調整，不理它」的消極含義；使用者選 C 仍是一次附理由的實質決策，語意上等同 batch_50 Q3 的「刻意不收緊」，而非放棄判斷。**PROXY 代打比對歷史模式時，不可只看選項字母（A/B/C）比對，必須讀選項語意對應何種決策類型再比對。**
- **B-傾向-2：需要調整規則時偏好根治/結構型方案 over 輕量關鍵字修補 — 累積 7 題全選結構型（batch_48 4/4＋batch_50 2/2＋本批 Q1）。** batch_48 4/4（產業類別解析、統計行結構性跳過、建廠信號豁免詞、E5/E6 擴充＋D6b 加重）＋ batch_50 兩道收緊題（Q1 收緊 E7 走「職安系學歷／EHS 年資佔比＋全履歷無 MEP 實質」結構判準、Q2 收緊 E15/E12 走「近段工作內容主軸＝大樓設施維運且無建廠/設計/監造，不因 title=機電工程師豁免」）＋ 本批 Q1（E19 修 context 判斷：軍種字眼須本人軍職才致命，落工程/專案 context 則豁免；選 A 而非 B 的「保守版僅豁免明確工程專案」窄版修補）皆為結構性方案而非單純加關鍵字或窄版特例。不接受頭痛醫頭的補丁。

### B-傾向-3：「收緊」只針對排除級漏網，不針對降級級邊界（正式模式，呼應閘門 A 三層分界線）

**使用者的規則收緊意願綁定候選人分級**：對「清楚偏離 MEP 且無工程實質」的**排除級**漏網之魚 → 選收緊排除規則；對「已判降級觀察」的**邊界/潛力型** → 選不收緊 /filter，保護「寧可多選不可漏選」，僅記 iteration_log。
