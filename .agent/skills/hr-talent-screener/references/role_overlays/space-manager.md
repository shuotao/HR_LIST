# space-manager — 空間管理工程師 overlay

> **本檔為人類可讀的 overlay 規格快照**。程式碼權威來源：`screen_candidates.py:get_overlay('space-manager')` 與評分權重 `web/backend/bim_scorer.py:ROLE_WEIGHTS['space-manager']`。當文件與程式碼不一致，**以程式碼為準**並回頭修文件。
>
> 當前版本：**v0.8**（2026-07-09，落地長期未實作的 D14 傳統基層降級；本輪 2 人誤選 + 1 人漏選回饋）。

---

## 一、角色定義

中鼎工程系統部「空間管理工程師（Space Manager / 建廠整合 / 系統整合工程師）」職缺：
- 透過 BIM 做 **跨系統的空間整合**：機電、結構、建築多領域協調
- 法規理解：建築技術規則、消防法規、無障礙、綠建築、PIC/S、GMP、IECC、ASHRAE、NFPA
- CSD/SEM、套圖、二次審圖、界面協調
- 高科技廠房的空間規劃、淨高/淨空管理、機房/管道間配置

**風格**：**做廣** — 不深耕單一系統，重在多系統的整合協調與規範對齊。

## 七、樣本特徵

### 正面樣本

- AECOM / 科進栢誠 / Jacobs / Arup 的 BIM Coordinator（顧問業）
- 大型 EPC 公司的 CSD/SEM 整合工程師
- 建築事務所轉做 BIM 整合（命中 N19 + N20）
- 機電顧問公司的審圖工程師（命中 D12 例外 ② CSD 例外）

### 反面樣本

- 純結構/柱樑/RC 工程師（D13 排除）
- BIM 講師（D11 排除）
- 純建模員 4 段短期經歷（D12 排除）
- 傳統水電工/監工無 BIM/空間/法規亮點（D14 排除）
- 化妝/文學學歷且希望職稱也沒寫 Space Manager 等差異化字眼（E14 排除）

詳見 `iteration_log.md` Batch 31-32 (space-manager + default (MEP) 聯合分析)。
